# Cherry Books

Повноцінний локальний проєкт книгарні: Go + ASP.NET Core 10 + PostgreSQL 17. Інтерфейс українською й англійською, світла та темна теми за палітрою референсу.

## Запуск через Docker

1. Встановіть Docker Desktop із Docker Compose.
2. Скопіюйте `.env.example` у `.env` у цій папці. Задайте випадкові `DB_PASSWORD`, `ADMIN_PASSWORD` (мінімум 12 символів) та власний `ADMIN_EMAIL`.
3. Виконайте `docker compose up --build -d`.
4. Відкрийте http://localhost:8080. Увійдіть за даними адміністратора, які ви задали. Кнопка «Адмінпанель» розташована в особистому кабінеті.
5. Зупинка: `docker compose down`. Дані зберігаються в іменованому томі `postgres-data`. Не додавайте `-v`, якщо потрібно зберегти дані.

Адміністратор створюється під час першого запуску, якщо його email ще відсутній у базі. Зміна ADMIN_PASSWORD не змінює пароль уже створеного облікового запису. Щоб призначити іншого адміністратора, використайте новий email і перезапустіть API. Не використовуйте email вже наявного покупця для створення адміністратора.

## Архітектура

Браузер → Go gateway :8080 → ASP.NET Core API :5080 → PostgreSQL.

Go видає HTML/CSS/JS, додає заголовки захисту та проксіює `/api/`. ASP.NET Core зберігає користувачів, сесії, каталог і замовлення. Усі SQL-запити параметризовані. Ціни — цілі копійки; сервер сам визначає підсумок. Залишки блокуються й списуються в одній транзакції із замовленням. Дві паралельні покупки не можуть продати останній примірник двічі. Скасування адміністратором повертає товар на склад один раз.

Кошик і налаштування теми/мови зберігаються в localStorage. Паролі та облікові записи там не зберігаються. Паролі хешуються PBKDF2-SHA512 з унікальною сіллю; сесії — випадкові токени в HttpOnly/SameSite=Strict cookie, у базі лише SHA-256 токена. Для запитів зміни даних перевіряється Origin. Вхід і реєстрація мають обмеження частоти. Права адміністратора перевіряє API на кожному запиті.

## Можливості

- 32 реальні книги із ISBN і обкладинками Open Library; пошук за назвою обома мовами, автором та ISBN, категорії й сортування.
- Сторінка книги, кошик зі зміною кількості, реєстрація та вхід, вихід, оформлення замовлення з адресою та телефоном.
- Кабінет із власними замовленнями та статусами. Покупець не бачить замовлень інших.
- Адміністратор додає/редагує книги, ціну, залишок, описи обома мовами, обкладинку, видимість і добірку. Приховування не видаляє історію замовлень.
- Адмінпанель замовлень із переходами Нове → Підтверджено → Відправлено → Виконано; скасування доступне до відправлення.
- Статистика показує суму замовлень, а не фактично отримані платежі.

## Книги й оплата

Усі початкові видання — англійською, що явно зазначено на картках. Українські назви — переклад для навігації. Ціни та залишки початкового каталогу — демонстраційні; реальних постачальників і складу до цього проєкту не підключено. Оригінальні обкладинки з Open Library збережені у web/covers і видаються самим сайтом. Дані каталогу в `db/books.json` засіваються лише один раз; перезапуск не перезаписує зміни адміністратора.

Підтвердження оформлює справжній запис замовлення в PostgreSQL. Метод оплати — при отриманні. Картковий еквайринг, автоматичні накладні доставки й email-сповіщення не підключені. Довідники міст і відділень Нової пошти інтегровані через офіційний API. Тариф доставки не включено в суму книг.

Джерела для перевірки книжок: https://www.matthaig.com/books/midnight-library/ та https://www.penguinrandomhouse.com/books/543993/atomic-habits-by-james-clear/ ; обкладинки https://openlibrary.org/dev/docs/api/covers .

## Запуск без Docker

Потрібні Go 1.23+, .NET SDK 10 і PostgreSQL 17. API використовує офіційну нативну бібліотеку PostgreSQL libpq (Linux: пакет libpq5; Windows: папка bin установленого PostgreSQL, задайте PG_LIB_DIR її абсолютним шляхом та додайте цю папку до PATH). Сторонніх NuGet-пакетів немає. Створіть базу `cherrybooks`. Задайте змінні середовища API:

```
DATABASE_URL=Host=localhost;Port=5432;Database=cherrybooks;Username=cherry;Password=YOUR_PASSWORD
ADMIN_EMAIL=YOUR_ADMIN_EMAIL
ADMIN_PASSWORD=YOUR_RANDOM_PASSWORD
PUBLIC_ORIGIN=http://localhost:8080
COOKIE_SECURE=false
```

Запустіть `dotnet run --project api/CherryBooks.csproj`. В іншому терміналі перейдіть у `gateway` і виконайте `go run .`. API застосує ідемпотентну початкову схему автоматично. Для подальших змін структури слід додавати версійні міграції.

## Публічне розгортання

Це проєкт для Docker/VPS із Go та .NET, він не запускається на хостингу Sites (Cloudflare Workers). Публічний сайт: https://cherry-books.onrender.com . Перед зовнішнім доступом потрібні домен і HTTPS через reverse proxy, точний PUBLIC_ORIGIN та COOKIE_SECURE=true, зовнішні секрети й резервне копіювання PostgreSQL. Не відкривайте порт бази даних у мережу. Поточний Compose прив’язує сайт лише до 127.0.0.1. Відновлення пароля, підтвердження email та аудит адміністративних змін у цю версію не входять.



## Окреме адміністрування

Вхід адміністратора: /admin/login/; панель: /admin/. Покупці реєструються через email і пароль. Google OAuth вилучено. API /api/admin/login перевіряє роль до створення сесії. Облікові дані адміністратора задані в секретах Render; запуск не змінює наявний пароль.

Адміністратор може фільтрувати замовлення за статусом, шукати за номером/іменем/телефоном, додати номер накладної після підтвердження й позначити замовлення відправленим. Покупець бачить накладну у своєму кабінеті.
