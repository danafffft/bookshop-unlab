# Поточна перевірка Cherry Books

Оновлення: 32 книги з локально збереженими оригінальними обкладинками; окремі головна, каталог із пагінацією, сторінка книги, про нас, контакти, доставка, FAQ, вхід, реєстрація, кошик, оформлення, кабінет і адмінпанель.

Збірка ASP.NET Core пройшла: 0 помилок і попереджень. Синтаксис web/app.js та tests/integration.mjs перевірено Node. Три тести Go пройшли раніше.

Офіційний API Нової пошти перевірено: getCities і getWarehouses відповідають без ключа для довідників. Сервер перевіряє вибрані референси перед збереженням замовлення. Ціна доставки не вигадується, автоматичні накладні не створюються.

Для клієнта реалізовано скасування власного нового або підтвердженого замовлення: транзакція, блокування рядка, перевірка власника, одноразове повернення залишків. Скасоване чи відправлене замовлення не можна скасувати повторно.

GitHub Actions запускає інтеграційний сценарій на ізольованій PostgreSQL, окремій від робочої бази. Його результат слід перевіряти для конкретного commit у вкладці Actions. Локальна спроба такого сценарію обмежена забороною TCP-з’єднань у середовищі Windows.

Google-вхід реалізовано, але не підтверджено наскрізно: потрібні GOOGLE_CLIENT_ID і GOOGLE_CLIENT_SECRET з вашого Google Cloud. Точні кроки — GOOGLE-SETUP.md.
