# Перевірка оновлення

ASP.NET Core: збірка без помилок. Node: синтаксис перевірено. DOM-сценарії: 13 сторінок та окремий вхід адміністратора. Доставка: запізніла відповідь попереднього міста ігнорується; пункт з API обов’язковий; графік показується; перемикання мови зберігає заповнену форму; новий пошук негайно скидає старий пункт.

Інтеграційний сценарій GitHub Actions працює в ізольованій PostgreSQL: реєстрація, сесії, ролі, окремий admin login, CSRF, приватність замовлень, ціни/залишки, скасування, живі довідники й пагінація Нової пошти, нормалізація телефону, контроль накладних, заборона скасування відправленого замовлення. Результат нового commit перевіряється перед передачею.

Google OAuth вилучено за запитом власниці. Дані адміністратора і замовлення збережені. Міграція додає необов’язкове поле tracking_number.
